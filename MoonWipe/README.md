# MoonWipe 1.0.0

Плагин безопасного ручного и автоматического полного вайпа для MoonEclips.

## Совместимость
- Paper 1.21.4
- Java 21
- Vault + работающий Economy provider (например, EssentialsX Economy)
- EconomicMoonEclips — необязательно, но поддерживается очистка его аукциона по SQLite-схеме 1.7.0
- LuckPerms — данные групп и привилегий не изменяются

## Возможности
- Ручной запуск через GUI и команды.
- Настраиваемое расписание: день недели, время и часовой пояс.
- Предупреждения обратного отсчёта.
- Резервная ZIP-копия до очистки.
- Обнуление балансов через Vault Economy API с проверкой результата и попыткой отката при ошибке.
- Очистка таблиц `listings` и `item_mail` в `auction.db` EconomicMoonEclips; файл базы и конфигурация сохраняются.
- Подготовка двухфазной очистки миров: старые каталоги удаляются на следующем старте до загрузки мира.
- Сохранение JAR-файлов, конфигураций плагинов, LuckPerms и схем WorldEdit.

## Команды
- `/mwipe` — открыть GUI.
- `/mwipe start` — открыть подтверждение ручного вайпа.
- `/mwipe confirm` — подтвердить запуск обратного отсчёта.
- `/mwipe cancel` — отменить обратный отсчёт.
- `/mwipe backup` — создать резервную копию без вайпа.
- `/mwipe schedule <DAY> <HH:mm>` — включить расписание.
- `/mwipe schedule off` — выключить расписание.
- `/mwipe status` — показать состояние.
- `/mwipe reload` — перезагрузить конфигурацию.

## Важное поведение
После подтверждённого вайпа плагин сохранит резервную копию, очистит экономику и аукцион, запишет план удаления миров и корректно остановит сервер. При следующем запуске план удалит старые каталоги миров до их загрузки; Paper создаст новый мир с именем из `settings.new-world-name`.

Хостинг должен автоматически запускать сервер после штатной остановки либо администратор должен запустить его вручную. Сам плагин не может гарантировать перезапуск JVM средствами Bukkit.

## Сборка
Java 21 + Maven: `mvn -B clean package`.
JAR: `target/MoonWipe-1.0.0.jar`.
