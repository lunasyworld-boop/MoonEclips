# MoonWipe 1.0.0 — техническое задание

## 1. Назначение

Отдельный Paper-плагин для безопасного ручного и автоматического полного вайпа MoonEclips. Цель — очистить игровой сезон и экономику, сохранив привилегии игроков, установленные плагины и их конфигурации.

## 2. Среда

- Paper 1.21.4
- Java 21
- Vault API 1.7.1
- Economy provider через Vault (на сервере MoonEclips — EssentialsX Economy)
- EconomicMoonEclips: очистка SQLite-аукциона при совпадении проверенной схемы
- LuckPerms: данные и группы не изменяются

## 3. Функциональные требования

### 3.1 Ручной режим
- /mwipe открывает административное GUI.
- /mwipe start подготавливает подтверждение.
- /mwipe confirm запускает обратный отсчёт.
- В GUI требуется отдельное нажатие «Подтвердить вайп».
- /mwipe cancel отменяет активный обратный отсчёт.

### 3.2 Автоматический режим
- Выбор даты и времени одноразового вайпа в GUI /mwipe menu без ограничения на недельный цикл.
- Выбор дня недели и времени для повторяющегося расписания командой /mwipe schedule <DAY> <HH:mm>.
- Отключение: /mwipe schedule off.
- В GUI доступны переключатели сброса миров, балансов Vault и аукциона EconomicMoonEclips; неизвестные плагины не очищаются без проверенного адаптера.
- Часовой пояс задаётся в config.yml: schedule.timezone (system или IANA, например Europe/Berlin).
- Расписание по умолчанию выключено, чтобы плагин не запускал вайп без явного включения.
- Начало обратного отсчёта рассчитывается так, чтобы завершить вайп к заданному времени.

### 3.3 Предупреждения
- Обратный отсчёт задаётся в settings.countdown-seconds.
- Предупреждения по умолчанию: 5 минут, 1 минута, 30 секунд, 10 секунд и последние 5 секунд.
- Во время обратного отсчёта новые подключения блокируются.

### 3.4 Резервная копия
До любых разрушительных действий создаётся ZIP в plugins/MoonWipe/backups/.
Копируются:
- активные каталоги миров и целевой новый мир, если он уже существует;
- plugins/Essentials/userdata;
- plugins/EconomicMoonEclips/auction.db и auction.yml, если найдены;
- server.properties.

Если резервное копирование выключено или не удалось, вайп отменяется.

### 3.5 Экономика
- Балансы игроков читаются и изменяются через Vault Economy API.
- Для поиска офлайн-аккаунтов используются Bukkit.getOfflinePlayers() и UUID-файлы EssentialsX.
- Каждый результат проверяется повторным чтением баланса.
- При ошибке выполняется попытка отката уже изменённых балансов; вайп отменяется.
- LuckPerms не используется для экономики и не изменяется.

### 3.6 Аукцион EconomicMoonEclips
- Плагин читает имя SQLite-файла из plugins/EconomicMoonEclips/auction.yml (auction.database-file).
- Перед очисткой EconomicMoonEclips отключается, чтобы закрыть его соединение с БД.
- Очищаются только таблицы listings и item_mail.
- Файл базы, таблицы, конфигурация и остальные файлы плагина сохраняются.
- Если ожидаемые таблицы отсутствуют, операция прерывается; исходный файл базы восстанавливается из снимка, балансы откатываются, миры не удаляются.
- Проверенная структура взята из исходного кода EconomicMoonEclips 1.7.0. Если установленная версия имеет другую схему, очистка намеренно остановится вместо удаления неизвестных таблиц.

### 3.7 Игровые миры и прогресс
- В список очистки входят все загруженные миры, дополнительные папки из worlds.additional, а также каталоги нового мира и его измерений.
- Список проверяется на безопасные имена и не может указывать на системные каталоги сервера.
- План удаления записывается в plugins/MoonWipe/pending-wipe.yml.
- Сервер штатно останавливается.
- На следующем старте, на этапе onLoad до загрузки мира, плагин удаляет указанные каталоги.
- Paper создаёт новый мир с именем settings.new-world-name.
- Удаление каталогов миров сбрасывает хранящиеся в них инвентари, эндер-сундуки, playerdata, advancements и stats.

## 4. Данные, которые сохраняются

- LuckPerms: группы, привилегии, временные назначения и пользовательские данные.
- JAR-файлы и конфигурации плагинов.
- plugins/EconomicMoonEclips/ и структура auction.db.
- plugins/Essentials/userdata: файлы сохраняются, балансы обнуляются через Vault.
- plugins/WorldEdit/schematics, включая hub-spawn.schem.
- plugins/MoonWipe/config.yml и резервные копии.

## 5. Команды и права

Право: moonwipe.admin (по умолчанию OP).

- /mwipe — GUI.
- /mwipe start — подготовить подтверждение.
- /mwipe confirm — подтвердить.
- /mwipe cancel — отменить обратный отсчёт.
- /mwipe backup — создать резервную копию без вайпа.
- /mwipe schedule <DAY> <HH:mm> — задать расписание.
- /mwipe schedule off — отключить расписание.
- /mwipe status — показать состояние.
- /mwipe reload — перечитать конфигурацию.

## 6. Конфигурация

Основные параметры:
- settings.new-world-name
- settings.countdown-seconds
- settings.reset-economy
- settings.reset-auction
- settings.reset-worlds
- backup.enabled
- backup.directory
- worlds.additional
- schedule.enabled
- schedule.mode (weekly или once)
- schedule.date (для одноразового запуска)
- schedule.day
- schedule.time
- schedule.timezone

## 7. Ограничения первой версии

- Плагин не может гарантировать автоматический запуск JVM после штатной остановки. На Veroid нужно включить автоматический перезапуск после остановки либо запускать сервер вручную.
- EssentialsX homes/mail и другие поля пользовательского профиля намеренно не удаляются: формат может отличаться между версиями EssentialsX. Файлы userdata сохраняются, а деньги обнуляются через Vault.
- Банковские счета Vault, если они включены отдельно от личных балансов, в этой версии не сбрасываются.
- Прогресс сторонних плагинов, который хранится вне каталогов миров и не имеет отдельного адаптера, не удаляется автоматически.
- Спавн из hub-spawn.schem сохраняется, но после вайпа его нужно вставить в новый мир через WorldEdit.

## 8. Критерии приёмки

1. Maven-сборка на Java 21 завершается успешно.
2. Плагин загружается на тестовом Paper 1.21.4.
3. GUI доступно только игрокам с moonwipe.admin.
4. Без резервной копии вайп не начинается.
5. Балансы обнуляются и проверяются через Vault.
6. При несовпадении схемы аукциона вайп прерывается, а данные восстанавливаются.
7. После штатной остановки и нового запуска старые миры отсутствуют, Paper создаёт новый.
8. LuckPerms, конфигурации плагинов и WorldEdit-схемы остаются на месте.
9. Проверены отмена таймера, ручной запуск и расписание на тестовом сервере.
