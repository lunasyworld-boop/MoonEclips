# Установка MoonWipe 1.0.0

## Требования
- Paper 1.21.4
- Java 21
- Vault
- EssentialsX Economy с зарегистрированным Vault Economy provider
- Для очистки аукциона — EconomicMoonEclips с совместимой SQLite-схемой (таблицы listings и item_mail)

## Получение JAR
1. Открой GitHub Actions репозитория MoonEclips.
2. Выбери последний запуск Build MoonWipe на ветке feature/moonwipe-1.0.0.
3. Убедись, что все шаги завершились успешно.
4. Скачай artifact MoonWipe-1.0.0.
5. Распакуй ZIP артефакта и возьми MoonWipe-1.0.0.jar.

## Установка на тестовый сервер
1. Сначала сделай отдельную резервную копию сервера.
2. Останови Paper.
3. Помести MoonWipe-1.0.0.jar в plugins.
4. Запусти сервер. Плагин создаст plugins/MoonWipe/config.yml.
5. Проверь консоль: MoonWipe должен включиться без ошибок.
6. Выполни /mwipe status.
7. Выполни /mwipe backup и проверь, что ZIP появился в plugins/MoonWipe/backups.
8. Проверь ручное подтверждение и отмену на тестовом сервере. Не запускай настоящий вайп на основном сервере до тестирования восстановления резервной копии.

## Настройка расписания
Пример включения субботнего вайпа в 14:00:
- /mwipe schedule SATURDAY 14:00

Отключение:
- /mwipe schedule off

Часовой пояс задаётся в plugins/MoonWipe/config.yml:
- system — часовой пояс системы хостинга;
- Europe/Berlin — явный часовой пояс Берлина;
- другой поддерживаемый IANA timezone — по необходимости.

## Важно для Veroid
MoonWipe выполняет штатную остановку сервера после подготовки вайпа. Проверь, что панель Veroid автоматически запускает сервер после штатной остановки. Если нет — после вайпа потребуется нажать «Запустить» в панели вручную.

## Перед первым настоящим вайпом
- Проверь, что ZIP резервной копии открывается и содержит мир, Essentials userdata, auction.db и server.properties.
- Убедись, что схема спавна сохранена отдельно в plugins/WorldEdit/schematics и находится вне папок удаляемых миров.
- Проведи пробный вайп на копии сервера.
- Не удаляй вручную папки plugins, LuckPerms, EconomicMoonEclips или WorldEdit.
