# MoonCases 1.21.0-b

Beta-проект кейсов для MoonEclips. Целевая среда: Paper 1.21.4, Java 21.

## Сборка
`mvn -B clean verify`; JAR: `target/MoonCases-1.21.0-b.jar`.

## Зависимости
- Paper 1.21.4
- LuckPerms 5.x (обязателен; API предоставляется сервером)

## Команды
- `/mcase menu` — меню кейсов
- `/mcase spawncase donate|titul` — поставить физическую бочку
- `/mcase delete donate|titul` — удалить зарегистрированную бочку
- `/mcase give <ник> <количество>` — выдать кейсы игроку онлайн
- `/mcase clear <ник> <количество>` — уменьшить число кейсов игрока
- `/titul` — коллекция титулов

## Важно
Перед запуском настройте `donate-groups` и награды в config.yml: вместо group2–group6 укажите реальные группы сервера. Пока реализована базовая beta-версия: сохранение бочек/балансов/титулов, GUI просмотра и выбора, случайная выдача, замена только перечисленных управляемых групп LuckPerms. Полная анимация, админ-GUI статистики/редактирования, безопасная транзакционная замена групп, offline-выдача и интеграционное исключение защиты спавна MoonHub ещё требуют реализации и тестирования. Не ставьте на основной сервер без проверки на копии.
