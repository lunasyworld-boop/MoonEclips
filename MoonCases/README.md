# MoonCases 1.21.1-b

Beta-плагин кейсов MoonEclips. Целевая среда: Paper 1.21.4, Java 21.

## Сборка
`mvn -B -f MoonCases/pom.xml clean verify`.
JAR: `MoonCases/target/MoonCases-1.21.1-b.jar`.

## Обязательная зависимость
- LuckPerms 5.x — установленный на сервере плагин. API подключается как provided и отдельно в JAR не встраивается.

## Команды
- `/mcase menu` — меню кейсов.
- ПКМ по зарегистрированной бочке — открыть соответствующий кейс.
- `/mcase spawncase donate|titul` — поставить бочку в блоке ног администратора; занятая позиция не перезаписывается.
- `/mcase delete donate|titul` — удалить регистрацию и только ту бочку, которая всё ещё помечена как кейс.
- `/mcase give <ник> <количество> [donate|titul]` — выдать кейсы офлайн- или онлайн-игроку; если тип не указан, выдаются donate-кейсы.
- `/mcase clear <ник> <количество> [donate|titul]` — уменьшить баланс.
- `/titul` — коллекция титулов.

## Что изменено в 1.21.1-b
- Раздельные балансы donate- и titul-кейсов; старый общий баланс beta переносится в donate.
- Физические бочки помечаются PersistentDataContainer. Удаление не затрагивает заменённый/чужой блок.
- Нельзя поставить кейс поверх занятого блока.
- GUI показывает относительный шанс каждой награды.
- Добавлена базовая анимация через ItemDisplay; реальные блоки мира не меняются.
- Открытие одной бочки блокируется на время анимации.
- Списание кейса выполняется только после успешной выдачи награды.
- При замене привилегии сохраняются посторонние группы/права LuckPerms; при ошибке сохранения выполняется попытка отката managed-групп.

## Настройка перед тестом
В `config.yml` замените `group2`–`group6` на настоящие имена управляемых групп сервера. Сейчас это placeholders, а не реальные привилегии MoonEclips. Проверьте конфигурацию наград и веса.

## Что ещё не завершено
- Полноценный админ-GUI для изменения шансов/названий/цен и просмотра статистики.
- Полная многоэтапная анимация по исходному ТЗ (с постепенным исчезновением и отдельным выигрышным блоком); текущая анимация — базовая beta.
- Интеграционное изменение обработчика защиты MoonHub. Открытие зарегистрированной бочки обрабатывается самим MoonCases, но совместимость нужно проверить на копии сервера с фактической сборкой MoonHub.
- Отображение выбранного титула возле ника.
- Полноценные runtime-тесты на Paper 1.21.4.

Это beta-сборка. Успешная компиляция не равна подтверждённой работе на живом сервере. Не устанавливайте на основной сервер до теста на копии.
