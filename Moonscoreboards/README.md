# Moonscoreboards 1.3.0-beta

Отдельный Paper-плагин для MoonEclips.

## Совместимость
- Paper 1.21.4 / Java 21
- Vault + Economy provider (EconomicMoonEclips использует Vault)
- LuckPerms 5.5.x

## Команды
- `/stats` — собственный профиль.
- `/pstats <ник>` — профиль любого игрока, право `moonscoreboards.admin` (по умолчанию OP).

## Данные
Монеты, группа LuckPerms и срок действия группы, убийства, смерти, K/D, время игры, первый/последний вход, уровень и мир (для игрока онлайн). Для офлайн-игроков игровая статистика читается из стандартного файла `world/stats/<uuid>.json`.

Пароли, IP-адреса и другие секретные данные не запрашиваются и не сохраняются.

## Оптимизация
- Одна общая задача обновления Scoreboard раз в 5 секунд.
- Персональный Scoreboard только на онлайн-игрока.
- Обновляются строки существующих команд без пересоздания Objective/Team.
- LuckPerms-кэш; загрузка пользователя только при отсутствии в памяти.
- Кэш и Scoreboard очищаются при выходе игрока.
- GUI создаётся только по запросу.

## Сборка
Java 21 + Maven: `mvn clean package`. JAR: `target/Moonscoreboards-1.3.0-beta.jar`.
